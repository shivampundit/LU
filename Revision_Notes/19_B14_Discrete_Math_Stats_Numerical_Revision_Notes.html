📌 1.1 Set Theory, Inclusion-Exclusion, Relations (Reflexive, Symmetric, Transitive), Equivalence & POSETs
Key Formulas & Rules
  • 🔹 For |A| = n: Power Set |P(A)| = 2^n
  • 🔹 Total Relations on A = 2^(n²)
  • 🔹 Reflexive Relations = 2^(n(n−1))
  • 🔹 Symmetric Relations = 2^(n(n+1)/2)
  • 🔹 Antisymmetric Relations = 2^n · 3^(n(n−1)/2)
  • 🔹 Functions A -> B (|A|=m, |B|=n) = n^m; Injective (1-1) = P(n, m)
Simple Exam Points
  • A binary relation `R ⊆ A × A` is: (1) **Reflexive** if `(a,a) ∈ R` for ALL `a ∈ A` (all main diagonal entries in relation matrix are 1, leaving `n² − n = n(n−1)` off-diagonal choices -> `2^(n(n−1))` relations)
  • (2) **Irreflexive** if `(a,a) ∉ R` for all `a` (`2^(n(n−1))`)
  • (3) **Symmetric** if `(a,b) ∈ R => (b,a) ∈ R` (`2^(n(n+1)/2)` relations)
  • (4) **Antisymmetric** if `(a,b) ∈ R` and `(b,a) ∈ R => a = b`
  • (5) **Transitive** if `(a,b) ∈ R` and `(b,c) ∈ R => (a,c) ∈ R`.
  • An **Equivalence Relation** is **Reflexive + Symmetric + Transitive** (partitions set A into disjoint Equivalence Classes
  • number of equivalence relations on n elements is the **n-th Bell Number B_n**: B_1=1, B_2=2, B_3=5, B_4=15, B_5=52).
  • A **Partial Order (POSET)** is **Reflexive + Antisymmetric + Transitive** (represented by a **Hasse Diagram**).
  • A Lattice is a POSET where every pair of elements has both a Least Upper Bound (LUB / Join) and Greatest Lower Bound (GLB / Meet).
✅ Direct Exam Example: Worked Relation & Function Count: Let `|A| = 3` and `|B| = 4`. Total functions from A to B = `4³ = 64`. One-to-One (Injective) functions from A to B = `4 × 3 × 2 = 24`. On set A (`n=3`), Reflexive relations = `2^(9−3) = 2^6 = 64`; Symmetric relations = `2^(3×4/2) = 2^6 = 64`; Equivalence relations = `B_3 = 5`.
💡 Exam Shortcut / Trap: Hinglish Tip: **Equivalence Relation = R + S + T** (Reflexive, Symmetric, Transitive — Bell Numbers: 1, 2, 5, 15, 52), jabki **Partial Order (POSET) = R + AS + T** (Reflexive, Antisymmetric, Transitive)! Aur n elements par Reflexive relations = `2^(n²−n)` aur Symmetric relations = `2^(n(n+1)/2)` hote hain!

(A) Power Set |P(A)| = 2⁵ = 32 subsets; Proper Subsets = 2⁵ − 1 = 31; Binary Relations on A = 2^(n²) = 2²⁵ ✅
(B) Power Set = 10; Relations = 2⁵
(C) Power Set = 25; Proper Subsets = 24
(D) Power Set = 64
Answer (A): For `|A| = n`: `|P(A)| = 2^n`; Total Relations on `A` = `2^(n²)`; Reflexive Relations = `2^(n(n−1))`; Symmetric Relations = `2^(n(n+1)/2)`.
Q1.2: What are the three required properties for a binary relation `R` on a set `A` to be (1) an 'Equivalence Relation' vs (2) a 'Partial Order Relation (POSET)'?
(A) Equivalence Relation is Anti-Symmetric
(B) Equivalence Relation = Reflexive + Symmetric + Transitive ✅
(C) POSET is Symmetric
(D) Neither requires Transitivity
Answer (B): Equivalence Relation = Reflexive + Symmetric + Transitive; Partial Order (POSET) = Reflexive + Anti-Symmetric + Transitive. Equivalence Relation = Reflexive + Symmetric + Transitive (partitions A into Equivalence Classes); Partial Order (POSET) = Reflexive + Anti-Symmetric + Transitive (drawn as a Hasse Diagram) — The ONLY difference is the middle property: Equivalence Relation requires **Symmetric** (`aRb => bRa`), whereas POSET requires **Anti-Symmetric** (`aRb and bRa => a == b`).
Q1.3: For two functions `f: A -> B` and `g: B -> C`, what makes a function 'Injective (One-to-One)', 'Surjective (Onto)', and 'Bijective'?
(A) A function is invertible even if it is not one-to-one
(B) Surjective requires |A| < |B|
(C) Injective (1-1): distinct inputs map to distinct outputs ✅
(D) Total functions from A(m) to B(n) is m^n (Correct is n^m)
Answer (C): Injective (1-1): distinct inputs map to distinct outputs; Surjective (Onto): Range == Codomain B; Bijective: Both One-to-One AND Onto. Injective (1-1): distinct inputs map to distinct outputs (requires |A| ≤ |B|); Surjective (Onto): Range == Codomain B (requires |A| ≥ |B|); Bijective: Both One-to-One AND Onto (invertible, requires |A| == |B|, total bijections = n!) — For `|A| = m, |B| = n`: Total functions `A -> B` = `n^m`; Injective (1-1) functions = `P(n, m) = n! / (n − m)!` (for `m ≤ n`); Bijections (when `m = n`) = `n!`.
Q1.4: In Set Theory, what is the Principle of Inclusion-Exclusion for two sets A, B and three sets A, B, C?
(A) |A ∪ B| = |A| + |B| + |A ∩ B|
(B) |A ∪ B| = |A| × |B|
(C) |A ∩ B| = |A| + |B|
(D) |A ∪ B| = |A| + |B| − |A ∩ B| ✅
Answer (D): |A ∪ B| = |A| + |B| − |A ∩ B|; |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |B∩C| − |A∩C| + |A∩B∩C|. Inclusion-Exclusion avoids double-counting elements belonging to intersections.

📌 2.1 Propositional Logic, Truth Tables, Conditional Contrapositive, Tautologies & First-Order Quantifiers
Key Formulas & Rules
  • 🔹 Implication p -> q ≡ ¬p ∨ q
  • 🔹 Contrapositive of (p -> q) is (¬q -> ¬p) [Logically Equivalent!]
  • 🔹 Converse is (q -> p)
  • 🔹 Inverse is (¬p -> ¬q)
  • 🔹 Negation ¬(p -> q) ≡ p ∧ ¬q
  • 🔹 De Morgan Quantifiers: ¬(∀x P(x)) ≡ ∃x ¬P(x)
Simple Exam Points
  • For `n` propositional variables, a truth table has `2^n` rows and there are `2^(2^n)` distinct truth tables.
  • The implication `p -> q` ('If p then q', 'p only if q', 'q is necessary for p', 'p is sufficient for q') is **FALSE ONLY WHEN `p` is True and `q` is False**!
  • Notice that an implication `p -> q` is ALWAYS logically equivalent to its **Contrapositive (`¬q -> ¬p`)**, and its **Converse (`q -> p`)** is logically equivalent to its **Inverse (`¬p -> ¬q`)**!
  • Classification of Formulas: **Tautology / Valid** (True in all rows, e.g., `p ∨ ¬p` or `((p -> q) ∧ p) -> q` Modus Ponens), **Contradiction / Unsatisfiable** (False in all rows, e.g., `p ∧ ¬p`), **Contingency** (mix of True and False rows), **Satisfiable** (True in at least ONE row).
  • Inference Rules: **Modus Ponens** (`p -> q, p ⊢ q`), **Modus Tollens** (`p -> q, ¬q ⊢ ¬p`), **Hypothetical Syllogism** (`p -> q, q -> r ⊢ p -> r`), **Resolution** (`p ∨ q, ¬p ∨ r ⊢ q ∨ r`).
✅ Direct Exam Example: English-to-Logic Translation Rules: '`p` only if `q`' = `p -> q`; '`p` if `q`' = `q -> p`; '`p` is a sufficient condition for `q`' = `p -> q`; '`p` is a necessary condition for `q`' = `q -> p`; '`p` unless `q`' = `¬q -> p ≡ p ∨ q`.
💡 Exam Shortcut / Trap: Exam Trap: `p -> q` ka **Negation** `p -> ¬q` NAHI hota — `¬(p -> q) ≡ ¬(¬p ∨ q) ≡ p ∧ ¬q` hota hai! Aur `p -> q` hamesha apne **Contrapositive (`¬q -> ¬p`)** ke barabar hota hai!

📝 Chapter 2 — Practice Questions & Simple Explanations

Q2.1: In Propositional Logic, when is the Conditional Implication `p -> q` ('If p then q') FALSE, and what is its logically equivalent 'Contrapositive'?
(A) `p -> q` is false when both p and q are false
(B) The Converse `q -> p` is logically equivalent to `p -> q`
(C) `p -> q` is FALSE ONLY when `p` is True and `q` is False ✅
(D) The Inverse `¬p -> ¬q` is equivalent to `p -> q`
Answer (C): `p -> q` is FALSE ONLY when `p` is True and `q` is False; its logically equivalent Contrapositive is `¬q -> ¬p`. `p -> q` is FALSE ONLY when `p` is True and `q` is False (`T -> F = F`); its logically equivalent Contrapositive is `¬q -> ¬p` (also equivalent to `¬p ∨ q`) — Memorize the pairs for `p -> q`: **Contrapositive `¬q -> ¬p` is ALWAYS equivalent to `p -> q`**; Converse (`q -> p`) and Inverse (`¬p -> ¬q`) are equivalent to each other, NOT to `p -> q`! A formula that is always True is a **Tautology**; always False is a **Contradiction**; sometimes True/False is a **Contingency**.
Q2.2: In Propositional Logic, what are the two laws of De Morgan for negation of AND (`∧`) and OR (`∨`)?
(A) ¬(p ∧ q) ≡ ¬p ∧ ¬q
(B) ¬(p ∨ q) ≡ p ∧ q
(C) ¬(p -> q) ≡ ¬p -> ¬q
(D) ¬(p ∧ q) ≡ (¬p ∨ ¬q) and ¬(p ∨ q) ≡ (¬p ∧ ¬q) ✅
Answer (D): Negating `p -> q` (`¬p ∨ q`) yields `p ∧ ¬q`!
Q2.3: What is the negation of the Quantified Predicate statement `∀x P(x)` ('For all x, P(x) is true') and `∃x P(x)` ('There exists an x such that P(x) is true')?
(A) ¬(∀x P(x)) ≡ ∃x ¬P(x); ¬(∃x P(x)) ≡ ∀x ¬P(x) ✅
(B) ¬(∀x P(x)) ≡ ∀x ¬P(x)
(C) ¬(∃x P(x)) ≡ ∃x ¬P(x)
(D) Quantifiers cannot be negated
Answer (A): De Morgan's Laws for Quantifiers flip `∀` to `∃` and `∃` to `∀` while moving `¬` inside.
Q2.4: In Propositional Logic Inference Rules, what are 'Modus Ponens' and 'Modus Tollens'?
(A) Modus Ponens: From `p -> q` and `q`, conclude `p` (Fallacy!)
(B) Modus Ponens: From `p -> q` and `p`, conclude `q` ✅
(C) Modus Tollens: From `p -> q` and `¬p`, conclude `¬q` (Fallacy!)
(D) Both are invalid fallacies
Answer (B): Modus Ponens: From `p -> q` and `p`, conclude `q`; Modus Tollens: From `p -> q` and `¬q`, conclude `¬p`. Remember: `p -> q` with `q` does NOT prove `p` (Fallacy of Affirming the Consequent)!

📌 3.1 Combinatorics, Permutations & Combinations, Stars-and-Bars, Pigeonhole Principle & Graph Handshaking Lemma
Key Formulas & Rules
  • 🔹 Stars & Bars (Non-negative integer solutions to x1 + x2 + ... + xk = n) = C(n + k − 1, k − 1) = C(n + k − 1, n)
  • 🔹 Derangements D_n = n!(1 − 1/1! + 1/2! − 1/3! + ... + (−1)^n/n!) (D_1=0, D_2=1, D_3=2, D_4=9, D_5=44)
  • 🔹 Handshaking Lemma: Σ deg(v) = 2|E|
Simple Exam Points
  • Generalized Pigeonhole Principle: If `N` objects are placed into `k` boxes, then at least one box contains at least `⌈N / k⌉` objects!
  • Circular Permutations of `n` distinct objects: `(n − 1)!` when clockwise and anti-clockwise orders are distinct (people around a table), and `(n − 1)!
  • / 2` when flip symmetry is identical (beads on a necklace/garland).
  • Graph Theory Fundamentals: By Euler's **Handshaking Lemma**, the sum of degrees of all vertices in an undirected graph equals **twice the number of edges (`Σ deg(v) = 2E`)**, which implies the **number of vertices of ODD degree is ALWAYS EVEN**!
  • Complete graph `K_n` has `n(n−1)/2` edges and is `(n−1)`-regular
  • Bipartite graph `K_(m,n)` has `m·n` edges and contains NO odd-length cycles (2-colorable)
  • a Planar Graph satisfies Euler's Region Formula **`V − E + R = 2`** and **`E <= 3V − 6`**!
✅ Direct Exam Example: Worked Combinatorics & Graph Math: (1) How many non-negative integer solutions exist for `x1 + x2 + x3 = 10`? Here `n = 10, k = 3` -> `C(10 + 3 − 1, 3 − 1) = C(12, 2) = 66`. (2) A connected planar graph has 10 vertices (`V=10`) and 15 edges (`E=15`). Number of regions `R = E − V + 2 = 15 − 10 + 2 = 7` regions.
💡 Exam Shortcut / Trap: Hinglish Tip: Kisi bhi undirected graph me **Odd Degree wale vertices ki sankhya hamesha EVEN (सम) hoti hai** (kyunki `Σ deg(v) = 2E`)! Aur Connected Planar Graph ke liye Euler's formula **`R = E − V + 2`** yaad rakhein!

Q3.1: According to the Handshaking Lemma in Graph Theory, for any undirected graph `G(V, E)`, what is the sum of degrees of all vertices `Σ deg(v)` equal to?
(A) |E|
(B) |V| + |E|
(C) 2|E| ✅
(D) |E|²
Answer (C): 2|E| (twice the number of edges — which implies that the number of vertices with ODD degree is ALWAYS EVEN!) — If a graph has 6 vertices each of degree 3, then `2|E| = 6 × 3 = 18 => |E| = 9` edges.
Q3.2: In a Simple Complete Undirected Graph `K_n` with `n` vertices, how many edges does `K_n` have, what is the degree of each vertex, and how many labeled Spanning Trees does `K_n` have (Cayley's Formula)?
(A) Edges = n²; Spanning Trees = 2^n
(B) Edges = n − 1; Spanning Trees = n!
(C) Degree = n
(D) Edges in K_n = n(n − 1) / 2; Degree of each vertex = n − 1; Labeled Spanning Trees = n^(n − 2) ✅
Answer (D): For `K₄` (`n = 4`): Edges = `4×3/2 = 6`, vertex degree = `3`, and labeled Spanning Trees = `4^(4−2) = 4² = 16`.
Q3.3: What is the exact degree condition for a connected undirected graph to possess an 'Euler Circuit' (traversing every EDGE exactly once and returning to start) vs an 'Euler Path'?
(A) Euler Circuit: ALL vertices must have EVEN degree ✅
(B) Euler Circuit requires all vertices to have odd degree
(C) Hamiltonian Cycle visits every edge once
(D) A tree always has an Euler Circuit
Answer (A): Euler Circuit: ALL vertices must have EVEN degree; Euler Path: Exactly 2 vertices have ODD degree. Euler Circuit: ALL vertices must have EVEN degree; Euler Path (not a circuit): Exactly 2 vertices have ODD degree — Note: **Euler** = visits every **Edge** once (easy degree test); **Hamiltonian** = visits every **Vertex** once (NP-Complete).
Q3.4: For a Connected Planar Graph with `V` vertices, `E` edges, and `R` faces (regions, including the infinite outer region), what is Euler's Planar Graph Formula?
(A) V + E + R = 2
(B) V − E + R = 2 ✅
(C) V − E − R = 0
(D) E = 3V + 6
Answer (B): V − E + R = 2 (and for any simple planar graph with V ≥ 3, E ≤ 3V − 6; if triangle-free/bipartite, E ≤ 2V − 4) — If a connected planar graph has `V = 6` vertices and `E = 9` edges, then the number of regions is `R = E − V + 2 = 9 − 6 + 2 = 5`.
Q3.5: According to the Pigeonhole Principle, if `n = 13` people are in a room, at least how many of them must share the exact same birth month (out of 12 months)?
(A) At least 3 people
(B) Exactly 1 person

📌 4.1 Linear Algebra — Matrix Rank, Determinants, System of Equations (AX = B), Eigenvalues & Cayley-Hamilton
Key Formulas & Rules
  • 🔹 For n×n Matrix A with Eigenvalues λ_1..λ_n: (1) Trace(A) = Σ a_ii = Σ λ_i
  • 🔹 (2) Det(A) = |A| = Π λ_i
  • 🔹 (3) Eigenvalues of A^k are λ_i^k; Eigenvalues of A^(−1) are 1/λ_i; Eigenvalues of (A + cI) are (λ_i + c)
Simple Exam Points
  • Matrix Properties: `Det(AB) = Det(A)·Det(B)`
  • for an `n×n` matrix, **`Det(k·A) = k^n · Det(A)`**
  • `(AB)^T = B^T · A^T` and `(AB)^(−1) = B^(−1) · A^(−1)`.
  • A square matrix `A` is invertible (non-singular) iff `Det(A) ≠ 0` iff `Rank(A) = n` iff `0` is NOT an eigenvalue of `A`.
  • Rouché–Capelli Consistency Theorem for Linear System `AX = B` (`n` unknowns): (1) If `Rank(A) ≠ Rank([A|B])` -> **Inconsistent (No Solution)**
  • (2) If `Rank(A) = Rank([A|B]) = n` -> **Unique Solution**
  • (3) If `Rank(A) = Rank([A|B]) = r < n` -> **Infinitely Many Solutions** (with `n − r` free variables / nullity!).
  • **Cayley-Hamilton Theorem** states that every square matrix satisfies its own characteristic equation `|A − λI| = 0`!
✅ Direct Exam Example: Worked Eigenvalue Numerical: Find the eigenvalues of `A = [[4, 2], [1, 3]]`. Trace = `4 + 3 = 7` (`λ1 + λ2 = 7`) and Determinant = `4(3) − 2(1) = 10` (`λ1 · λ2 = 10`). Numbers summing to 7 with product 10 are **`λ1 = 5` and `λ2 = 2`**! Then eigenvalues of `A² + 2I` are `(5²+2, 2²+2) = (27, 6)`.
💡 Exam Shortcut / Trap: Exam Trap: Eigenvalue questions ko 5 second me solve karne ka brahmastra: **Sum of Eigenvalues = Trace(A) (diagonal elements ka yog)** aur **Product of Eigenvalues = Determinant |A|**! Aur `|kA| = k^n |A|` hota hai (`k|A|` nahi)!

📝 Chapter 4 — Practice Questions & Simple Explanations

Q4.1: For the `2 × 2` matrix `A = [[4, 2], [1, 3]]`, what are its Trace, Determinant, and two Eigenvalues `λ₁, λ₂`?
(A) Eigenvalues are 4 and 3
(B) Eigenvalues are 6 and 1
(C) Trace = 4 + 3 = 7 ✅
(D) Determinant is 14
Answer (C): Trace = 4 + 3 = 7; Determinant = (4×3 − 2×1) = 10; Eigenvalues are λ₁ = 5 and λ₂ = 2 (since 5 + 2 = 7 and 5 × 2 = 10) — Shortcut: Never expand the characteristic polynomial `det(A − λI) = 0` in MCQs! Just check the options where **Sum of Eigenvalues = Trace(A) = 7** and **Product of Eigenvalues = det(A) = 10** (`5 + 2 = 7` and `5 × 2 = 10`)!
Q4.2: For a system of `n` linear equations `A X = B`, what is the condition on `Rank(A)` and the augmented matrix `Rank([A | B])` for the system to have (1) a Unique Solution, (2) Infinitely Many Solutions, and (3) No Solution (Inconsistent)?
(A) No Solution occurs when Rank(A) == Rank([A|B])
(B) Unique Solution occurs when det(A) == 0
(C) Homogeneous system AX = 0 can have No Solution
(D) (1) Unique: Rank(A) == Rank([A|B]) == n ✅
Answer (D): (1) Unique: Rank(A) == Rank([A|B]) == n; (2) Infinite: Rank(A) == Rank([A|B]) < n; (3) No Solution: Rank(A) < Rank([A|B]). By the Rouché–Capelli Theorem, a system is consistent iff `Rank(A) == Rank([A|B])`.
Q4.3: If a `3 × 3` square matrix `A` has determinant `det(A) = 5`, what is `det(2A)` and `det(A⁻¹)`?
(A) det(2A) = 2³ × 5 = 40; det(A⁻¹) = 1 / 5 = 0.2 ✅
(B) det(2A) = 2 × 5 = 10; det(A⁻¹) = −5
(C) det(2A) = 25; det(A⁻¹) = 5
(D) det(2A) = 15
Answer (A): For an `n × n` matrix: `det(kA) = k^n · det(A)`, `det(A^T) = det(A)`, `det(AB) = det(A)det(B)`, and `det(A⁻¹) = 1 / det(A)`.
Q4.4: When is a square matrix `A` called (1) Singular, (2) Symmetric, (3) Skew-Symmetric, and (4) Orthogonal?
(A) Singular has `det(A) = 1`
(B) Singular: `det(A) = 0` (no inverse) ✅
(C) Orthogonal has `A^T = −A`

Answer (B): Singular: `det(A) = 0` (no inverse); Symmetric: `A^T = A`; Skew-Symmetric: `A^T = −A`; Orthogonal: `A^T A = I`. 📖 Chapter 5: Probability & Bayes — Probability Axioms, Conditional Probability P(A|B), Independence & Bayes' Theorem

3 Questions in Booklet
📌 5.1 Probability Axioms, Conditional Probability P(A|B), Independence & Bayes' Theorem
Key Formulas & Rules
  • 🔹 P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • 🔹 Conditional P(A|B) = P(A ∩ B) / P(B)
  • 🔹 Independent Events: P(A ∩ B) = P(A)·P(B)
  • 🔹 Mutually Exclusive (Disjoint): P(A ∩ B) = 0
  • 🔹 Bayes' Theorem: P(B_i | A) = [P(B_i)·P(A | B_i)] / Σ_j [P(B_j)·P(A | B_j)]
Simple Exam Points
  • Crucial Distinction: **Mutually Exclusive vs Independent Events**: If two events A and B with non-zero probabilities (`P(A) > 0, P(B) > 0`) are **Mutually Exclusive** (`A ∩ B = ∅ => P(A ∩ B) = 0`), they can **NEVER be Independent** (since `P(A)·P(B) > 0 ≠ 0`), and vice versa!
  • For 'At least one' success problems (`P(A ∪ B)` when A, B are independent): always use the complement shortcut **`P(at least one) = 1 − P(none) = 1 − P(A')·P(B')`**!
  • Total Probability & Bayes' Theorem update prior probabilities `P(B_i)` into posterior probabilities `P(B_i | A)` given observed evidence `A`.
✅ Direct Exam Example: Worked Bayes & At-Least-One Math: (1) A solves a problem with probability `2/3` and B with `3/4`. Probability that the problem is solved = `1 − (1 − 2/3)(1 − 3/4) = 1 − (1/3)(1/4) = 1 − 1/12 = 11/12`. (2) Factory Machine M1 produces 60% of items (2% defective) and M2 produces 40% (5% defective). Given a randomly picked item is defective, probability it came from M2 = `(0.40 × 0.05) / (0.60×0.02 + 0.40×0.05) = 0.020 / (0.012 + 0.020) = 20 / 32 = 5/8 = 62.5%`.
💡 Exam Shortcut / Trap: Hinglish Tip: Agar `P(A) > 0` aur `P(B) > 0` hai, to **Mutually Exclusive** events kabhi **Independent** nahi ho sakte! Aur 'At least one solves the problem' ke liye hamesha `1 − P(A fails) × P(B fails)` lagayein!

📌 6.1 Descriptive Statistics (Mean, Median, Mode, Variance, CV), Correlation/Regression & Binomial/Poisson/Normal
Key Formulas & Rules
  • 🔹 Karl Pearson's Empirical Skewness Formula: Mode = 3·Median − 2·Mean
  • 🔹 Coefficient of Variation CV = (σ / Mean) × 100
  • 🔹 Binomial B(n,p): Mean = np, Var = npq (Mean > Var!)
  • 🔹 Poisson(λ): Mean = λ, Var = λ (Mean == Var!)
Simple Exam Points
  • Effect of Change of Origin & Scale (`Y = aX + b`): (1) **Mean, Median, Mode** shift by BOTH origin and scale (`Mean_Y = a·Mean_X + b`)
  • (2) **Standard Deviation `σ`** is **independent of change of origin (`+b`)** and scales by `|a|` (**`σ_Y = |a| · σ_X`**, and **Variance `Var(aX + b) = a² · Var(X)`**)
  • (3) **Karl Pearson's Correlation Coefficient `r ∈ [−1, +1]`** is independent of BOTH change of origin and scale (`r_XY = √(b_YX · b_XY)` — the Geometric Mean of the two regression coefficients, with the same algebraic sign!).
  • Probability Distributions: **Binomial `P(X=k) = C(n,k) p^k q^(n−k)`** has `Mean = np > Variance = npq`
  • **Poisson `P(X=k) = (e^(−λ) λ^k) / k!`** (rare events as `n -> ∞, p -> 0, np = λ`) has **`Mean = Variance = λ`**
  • **Normal (Gaussian) Bell Curve** is symmetric (`Mean = Median = Mode`, Skewness = 0, Kurtosis = 3 Mesokurtic, 68.27% within `μ ± 1σ`, 95.45% within `μ ± 2σ`, 99.73% within `μ ± 3σ`).
✅ Direct Exam Example: Worked Empirical Mode & Regression Math: (1) If Mean = 25 and Median = 26, then `Mode = 3(26) − 2(25) = 78 − 50 = 28`. (2) If the two regression coefficients are `b_YX = −0.8` and `b_XY = −0.2`, then Correlation Coefficient `r = −√(0.8 × 0.2) = −√0.16 = −0.4`.

Aur हर डेटा मान में `+10` जोड़ने पर **Standard Deviation और Variance में कोई बदलाव नहीं होता (Unchanged)**!

📌 7.1 Numerical Methods — Root Finding (Bisection, Regula-Falsi, Secant, Newton-Raphson) & Numerical Integration
Key Formulas & Rules
  • 🔹 Order of Convergence p: Bisection = 1 (Linear, guaranteed)
  • 🔹 Regula-Falsi = 1
  • 🔹 Secant = 1.618 (Golden Ratio)
  • 🔹 Newton-Raphson x_(n+1) = x_n − f(x_n)/f'(x_n) = 2 (Quadratic!)
  • 🔹 Simpson's 1/3 Rule (Even n, Degree <= 3 exact): (h/3)[(y_0 + y_n) + 4(Odd y_i) + 2(Even y_i)]
Simple Exam Points
  • Root-Finding Algorithms for `f(x) = 0`: (1) **Bisection Method (Bolzano)**: Requires `f(a)·f(b) < 0` on `[a,b]`
  • halves interval width every step (`|e_n| <= (b−a)/2^n`), **Order of Convergence = 1 (Linear)**, slowest but 100% guaranteed to converge
  • (2) **Newton-Raphson Method (Tangent Method)**: `x_(n+1) = x_n − f(x_n)/f'(x_n)`, **Order of Convergence = 2 (Quadratic — number of correct decimal digits doubles every iteration!)**, fails if derivative `f'(x_n) = 0`
  • (3) **Secant Method**: Replaces `f'(x)` with secant chord difference, Order = `1.618`.
  • Numerical Integration (Newton-Cotes Quadrature on `n` subintervals of width `h = (b−a)/n`): (1) **Trapezoidal Rule** (Linear polynomial degree 1, any `n`, Error `O(h²)`)
  • (2) **Simpson's 1/3 Rule** (Parabolic degree 2 interpolation, **strictly requires `n` to be EVEN**, exact for polynomials up to **degree 3 (cubics)**, Error `O(h⁴)`)
  • (3) **Simpson's 3/8 Rule** (Cubic degree 3 interpolation, **strictly requires `n` to be a MULTIPLE OF 3**, weights `1, 3, 3, 2, 3, 3, 1`, multiplier `3h/8`).
✅ Direct Exam Example: Worked Newton-Raphson Formula for Square Root `√N`: To find `x = √N`, solve `f(x) = x² − N = 0` (`f'(x) = 2x`). Substituting into Newton-Raphson gives the famous Heron iterative formula: **`x_(n+1) = x_n − (x_n² − N)/(2x_n) = (1/2) · (x_n + N / x_n)`**!
💡 Exam Shortcut / Trap: Hinglish Tip: **Newton-Raphson** ka Order of Convergence **2 (Quadratic)** hota hai! **Simpson's 1/3 Rule** ke liye subintervals `n` ka **EVEN (सम संख्या: 2, 4, 6...)** hona 100% anivarya hai, aur **Simpson's 3/8 Rule** ke liye `n` ka **Multiple of 3 (3, 6, 9...)** hona zaroori hai!
